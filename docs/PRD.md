# 产品需求文档 PRD · V1.0

调研基线：2026-11-26。产品暂名 AI Lesson Studio（智能备课工作台）；当前仅完成 Skill 原型，以下为拟开发需求。

## 背景与真实案例

教师有教材、专项练习、扫描试卷等资料，需要整理为培训机构统一的 Word 教案。一份四页五年级上册英语 Unit 1–4 练习含 120 道独立编号小题（题组 A 77、B 43）；机构模板包含教案基本信息、目标、重难点、教学过程竖栏、外框、课前审核、学生评价、成长记录及课后审核。初版曾丢失续页边框、将正文放在表格之外，后续修正成 8 页。原题还原、模板保真与分页是真实已发现问题，其余需求需访谈验证。

## 用户与痛点

| 用户 | 痛点 | 优先级 |
|---|---|---|
| 教培/一对一英语教师 | 扫描题逐个录入、知识点归纳、固定教案制作、分页返工 | P0 |
| 兼职辅导老师 | 时间紧、重复备课、操作复杂 | P0 |
| 中小学教师 | 不同学科的教学资料加工、教案复用 | P1 |
| 教研组负责人 | 统一标准与教案审核 | P1 |
| 机构管理者 | 权限、教案共享、审核留档 | P2 |

核心价值：把已有资料可靠加工为可审核、可编辑、可打印的教案，而非仅生成一段教学文字。

## 核心流程

新建教案 → 上传资料/模板 → 解析 → 原题对照确认 → AI 教学分析 → 内容编辑 → 真实分页预览 → 验收 → Word 下载。

## 功能范围

| 模块 | P0 首版 | P1/P2 |
|---|---|---|
| 工作台 | 新建、历史、教学基本信息 | 草稿复制、批量任务 |
| 资料管理 | PDF/Word/图片，多文件排序 | 资源库 |
| 文档解析 | 文本提取、OCR、题号/选项/划线/留白、来源定位 | 复杂公式/几何图 |
| 原题确认 | 原图与识别文字左右对照、手动修正、数量核对 | 批量审核 |
| 教学设计 | 目标、重难点、知识点、原题训练、课后小结 | 答案解析、教师版 |
| 模板 | 固定内置模板，首页/续页/末页 | 自定义模板适配、模板设计器 |
| 编辑 | 内容、题目、教学信息可改 | 局部 AI 重写 |
| 输出 | Word、分页预览、质量校验 | PDF 下载、批量导出 |
| 模型 | BYOK 配置供应商/Key/Base URL/模型、连接测试与调用日志 | 平台统一模型、本地模型 |
| 机构与学情 | 暂不做 | 账号、审核、学生错题、学情 |

## 交互方案

PC 优先，三栏工作台：左侧原始资料与页码定位，中间结构化教学内容编辑，右侧真实 DOCX 转 PDF 的分页预览。明确区分识别中、待确认、生成中、待验收、已导出、失败状态；支持从失败步骤重试，不重复上传和识别。

## 验收标准（建议目标，尚未实测）

| 指标 | 目标 |
|---|---|
| 教师总备课用时 | 相比人工减少 ≥60% |
| 独立编号原题数量完整率 | 100% |
| 首次原题识别准确率 | ≥98%，以逐题完全正确或明确字段准确率评估 |
| 人工确认后原题完整性 | 100%，歧义需显式记录 |
| 已适配模板受保护结构保留率 | 100% |
| 异常空白页 / 内容溢出 | 0 |
| 无需大量返工比例 | ≥90% |
| 教师再次使用意愿 | ≥80% |

建议 5–10 名真实教师、至少 30 份不同资料进行试用；先采集人工基线，再对比耗时、错误、重试、成本及满意度。

## 非目标及风险

首版不做全国教材资源库、完整 Word 在线编辑器、学生教务管理、支付、多租户、模型微调、复杂 Agent。扫描歧义须教师确认；原题图形可先保留源图，不承诺所有公式可编辑。学生信息、机构标志与教学资料版权须最小化处理及授权。教师反馈/审核签字不得自动编造。
