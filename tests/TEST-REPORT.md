# V1.0 回归测试记录

测试环境：当前 Linux 容器、Python、python-docx、LibreOffice、PyMuPDF；未在 Windows Word/WPS 实机执行。

- PDF 解析：用户上传的《五上语法训练(1).pdf》扫描件，成功输出 4 页 PNG 与资料清单。无可用文字层时由 AI 看图转写，不自动 OCR。
- 完整样例：复用上轮已生成的英语边框版教学内容制作 JSON 回归样例，原题 ID 共 120（A 77，B 43）。修复 A 五第 7 题末尾答题线。该样例用于模板与内容传递回归，不等同于独立重新转写原件的精确率测试。
- 自动测试：4 项通过（完整样例结构、边框篡改检出、缺失 ID、重复 ID、最小样例；完整样例与边框检测合在一项）。
- 实际生成：8 个外表、8 个渲染页。首次渲染出现 13 页，定位为默认文档网格吸附导致行高膨胀；对新正文禁用 snapToGrid 后恢复 8 页。页眉页脚、媒体、边框、受保护单元格、计划文字与段落下划线均通过脚本检查。见 `regression-report.json`。
- 视觉核查：8 页预览检查首、续、末页框线及竖栏，未见额外空白页、明显溢出、页眉页脚重叠。此测试不保证其他字体环境分页完全一致。
- 未覆盖：任意新机构模板、复杂数学公式/几何图、独立扫描识别准确率、Word/WPS 渲染一致性、批量多份文件端到端实测。新任务仍需实际源图逐题复核。
